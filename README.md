# Stealth Game

A stealth game developed with Unity.

## Controls

| Key | Action |
|---|---|
| W | Move up |
| A | Move left |
| S | Move down |
| D | Move right |
| Left Mouse Button | Shoot |
| E | Pick up an item |
| Q | Drop an item |

## Features

- WASD movement
- Shooting mechanics
- Item pickup and drop system
- Stealth gameplay

This project is currently in development. More features and improvements may be added in the future.
